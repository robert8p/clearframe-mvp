# Cogni content method — six learning contexts

Cogni trains transferable judgement rather than recall trivia. Every scored challenge is mapped to one or more skills and has deterministic answer logic, an explanation, a thinking principle, an AI-age application and error-pattern metadata. Correct answers remain server-side.

## Learning contexts

Cogni currently supports six contexts:

1. **Casual / personal growth** — curiosity-led learning for everyday choices, online information and AI.
2. **University student** — study, AI-assisted learning and graduate readiness.
3. **Graduate / early career** — trusted work, communication and early professional judgement.
4. **Junior professional** — stronger recommendations and evidence-led professional decisions.
5. **Management** — people, priorities, resources, delivery and risk.
6. **Executive** — strategy, transformation, governance and uncertainty.

A context changes examples, situations, language and the difficulty anchor. It does not classify intelligence, seriousness or potential. Skill scores remain on one continuous learner history when context changes.

The research and design definition for the Casual / personal-growth context is recorded in `CASUAL_LEARNER_RESEARCH.md`.

## Daily learning sequence

The current daily loop is:

1. **3-minute lesson** — a memorable story or example introduces one thinking move.
2. **Generate before reveal** — the learner writes a one-sentence instinct before seeing the worked reasoning. This text is deliberately ungraded.
3. **Adaptive judgement reps** — mixed interaction formats target weak or under-observed skills while preserving variety and an AI-verification component.
4. **Immediate feedback** — correctness or partial alignment, explanation, principle, application, error pattern, XP and skill movement.
5. **Personalised completion insight** — actual session evidence is translated into the next useful focus.

## Current content bank

The live bank contains **863 published challenges** and **111 published lessons**. Each learning context has a directly targeted pool of **126 published challenges**, including five starting-check questions, and **16 directly targeted lessons**. Shared content supplements those pools.

Every context covers all 15 Cogni judgement skills across the challenge bank. Question formats include:

- single choice;
- multi-select;
- ranking;
- classification;
- decision triage.

The Casual / personal-growth bank has full format parity and includes 120 scenario-skill combinations, five audience-specific starting-check questions and one integrated capstone. Its content covers health and wellbeing claims, purchases and reviews, AI-assisted travel, online charts, community decisions, privacy, personal trackers and urgent money/AI claims.

## Construction rules

Single-choice questions must not teach answer-position habits. Distractors should represent plausible reasoning errors, not joke answers. Every submitted answer receives corrective feedback because exposure to plausible incorrect alternatives can otherwise reinforce misinformation.

Story-led questions should use concrete, recognisable situations; keep the question decision-oriented; avoid unnecessary prose; and make the strongest answer defensible from the evidence presented rather than from test-taking tricks.

### Alternative formats

- **Multi-select:** use when more than one issue genuinely applies; partial credit measures discrimination.
- **Ranking:** use when relative strength or order is the judgement being trained.
- **Classification:** use when the key skill is distinguishing categories across several signals.
- **Triage:** use for realistic decisions where the core skill is choosing the safest or highest-value next move.
- **Generate-before-reveal:** use free response to prompt retrieval and generation, without pretending arbitrary prose is psychometrically graded.

## Safety and high-consequence content

Health, money, legal rights, privacy, safety and other consequential scenarios must not masquerade as advice. Their strongest responses should increase source quality, authoritative verification, human responsibility and reversibility as consequences rise.

## Content generation workflow

Future AI-assisted content should follow:

**Generate → validate answer logic → validate distractors/categories → check factual claims and sources → check duplication and format balance → human review → publish.**

Treat the current bank as pilot-quality training content, not a scientifically normed assessment bank. See `LEARNING_DESIGN_RESEARCH.md` and `CASUAL_LEARNER_RESEARCH.md` for the evidence and design rationale.
