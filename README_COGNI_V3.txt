COGNI UI V3 — MOBILE-FIRST REFERENCE MATCH

This patch is based on screenshots of the deployed app and the original design reference.
It removes the desktop-dashboard feel from consumer screens and replaces it with a phone-style mobile-first application shell:
- no left sidebar on consumer screens
- compact bottom navigation
- dense dashboard cards
- real daily-session progress
- recent/priority skill tiles
- AI study-buddy card
- visual weekly activity chart
- richer session-complete screen with actual session score and XP
- compact profile/achievement experience
- desktop-only internal admin/analytics shell

Replace/add all included files at the same relative paths, commit, and redeploy.
