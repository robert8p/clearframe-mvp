# Cogni 0.4.3 — clearer practice and progress

Download `Cogni-0.4.3-preview.apk` from this release on your Android phone and open it. Choose **Update**. Keep the existing Cogni installation; there is no need to uninstall or create a new account. Version **0.4.3** is shown in Profile and on the welcome screen.

## What to try

1. From Home, start or continue your check. Select an answer and, when asked, choose your confidence. No confidence value is chosen for you. Submit, read the explanation brought into view, then continue. Leave and return to confirm your next unanswered question resumes.
2. Open Progress and choose a skill in its history card. Inspect the actual recorded dates and scores. One recorded day is a starting point, not a trend. Expand the score explanation if you want more context.
3. In a lesson, reflect by typing or choose **I’ve reflected without typing**, then reveal the idea. Your reflection text stays in that screen; it is not submitted to the server.
4. In Profile, change sound and haptic preferences independently. Close and reopen Cogni. They should persist. Use Preview feedback to try the combination.
5. In Profile, change your password. Cogni now confirms **Password updated** before you leave. Use the new password next time you sign in.

The existing redesigned Home, Train navigation, skill search, calmer visual system and optional outcome sounds are retained from 0.4.2.

## Verification scope

The release workflow publishes this APK only after the exact source passes mobile and server checks, the signed APK passes identity/permission/checksum checks, Android upgrade and interaction suites pass, disposable test accounts are cleaned up, and the website and iOS JavaScript compile. The release's metadata and linked workflow identify the compiled commit and exact APK checksum.

This is an Android test preview. Paid subscriptions remain disabled. It is not a signed iPhone/TestFlight build. Real Apple/Google billing, physical sound/haptic quality, TalkBack/VoiceOver behaviour and recovery-email delivery/token redemption still need dedicated verification. The app provides curated thinking practice; arbitrary-topic live AI-generated learning is not implemented by this release.
