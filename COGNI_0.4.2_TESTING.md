# Cogni 0.4.2 — stakeholder-review test preview

Install `Cogni-0.4.2-preview.apk` over your existing Cogni installation. Do not uninstall first. The package and signing identity are unchanged; sign in with your normal account if needed. Version 0.4.2 is visible in Profile and on the signed-out welcome screen.

Start or continue training from the redesigned Home card. Submit an answer, inspect its explanation, go to the next question, leave and return. The question number should describe the current question, including while its answer feedback is visible.

Open Skills. Search for a skill, try the All skills / Practised / New filters, and tap a skill card. A skill with no observations should say Not measured yet, not present a seed score as an assessment. An unmatched search offers Reset filters.

Open Progress. A new account has No score yet; a genuine zero remains zero. Daily history needs at least two recorded dates before showing a change. The chart represents actual recorded days, not fabricated sample data.

In Profile → Sound and touch, try Preview feedback. Sound and haptics have separate persistent switches. Try the app with larger system text. Pull down on a main tab to refresh. After a failed refresh the current visit's view remains with a retry notice; a fresh offline launch does not show cached personal data.

This is not a paid store launch. Monetisation is disabled, and no live purchase/restore is possible in this pre-store build. iOS JavaScript compilation is not a signed TestFlight build. Emulator tests cannot establish the quality of physical sound, haptics or assistive-technology behaviour. See the stakeholder review and release verification record for precise scope and outstanding gates.
