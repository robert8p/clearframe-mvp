# R&D Log

## Genuine uncertainties worth preserving
1. Whether reasoning-error categories can be inferred reliably from response patterns/free text.
2. Whether adaptive selection materially outperforms static sequences for transfer to realistic work decisions.
3. Whether personalised explanations improve transfer rather than only item familiarity.
4. Whether confidence calibration improves through targeted intervention.
5. Whether AI-overreliance can be measured reproducibly without conflating domain knowledge.

## Evidence discipline
For each experiment record hypothesis, technological uncertainty, baseline, method, data, failed approaches, result, limitations, decision and architecture change. Do not backfill an R&D narrative after the fact.

## First experiment
Compare weak-skill adaptive sequencing against matched static sequencing. Primary learning endpoint: held-out transfer items not seen during training. Secondary endpoint: 7-day voluntary return rate.
