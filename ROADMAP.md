# Cogni roadmap

## Current — v0.7.0
Daily micro-lessons, mixed-format adaptive practice, balanced MCQs, partial credit, evidence-led Judgement Profile, persisted sessions and engagement motion.

## Next validation priorities
1. Instrument return rate and completion by lesson/question format.
2. Measure next-day/next-week retention by skill and format.
3. Test whether mixed-format practice improves transfer versus MCQ-only sessions.
4. Add a content-quality review workflow and admin authoring for all interaction types.
5. Add a weekly review that retrieves prior concepts rather than only summarising scores.
6. Calibrate difficulty and partial-credit rules from pilot response data.
7. Run a small human-labelled study before introducing any automated free-text scoring.

## Later
Validated psychometrics (IRT/BKT as appropriate), enterprise cohort reporting with privacy thresholds, SSO/SCIM, team challenges, subscriptions, native mobile and carefully validated normative comparisons.
