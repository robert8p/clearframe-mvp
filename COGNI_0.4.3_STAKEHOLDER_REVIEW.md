## Release contract

Visual readback found a further gap in 0.4.2's large-text evidence: Home copy, its CTA, the wordmark and tab labels clipped after a live font-scale change even though heading reachability assertions passed. The shared scroll content now remounts native text measurements when font scale changes, preserving the parent screen's learning/form state. Decorative wordmark text stays at its intended graphic size; five constrained tab labels grow to 120% with added vertical space, while learning content scales fully. Installed tests capture both a live change and cold launch at 160%; screenshots must be inspected rather than equating a found accessibility label with visible readable text.

The intermediate 0.4.3 build 60 passed automated run 34120458584, but visual review showed that remounting alone still reused stale native text measurements during live changes. Its preview is retained as a draft. A narrowly version-pinned Expo 54 / React Native 0.81.5 Android plugin now enables font-scale-aware cache identity before any React surface exists, while preserving the exact stable feature provider. It rejects unsupported versions, startup-order changes, a different architecture/release level, or an already-consumed font-scale flag. Keep the scroll-content remount as well: the upstream root-layout invalidation defect is separate. The Android suite now compares the complete training button’s dimensions at live versus cold 160%, and again after returning to 100%; the intermediate build’s measured heights were 154 versus 239 pixels, a real failure that label-presence checks missed.

`release/cogni-0.4.3` builds from the complete checked-in application and server source. The workflow applies explicit build-only EAS profile overrides for version increment, cache and public configuration; it does not patch application or server implementation during compilation. All jobs check out the triggering commit. APK metadata records the same commit; draft preparation verifies the checksum again and depends on source/server tests, native build/signature/permissions, Android upgrade and interactions, account cleanup, iOS JavaScript export and production web compilation. Public handoff follows a separate review of the captured native screenshots.

Only disposable accounts are used for mutation/deletion tests. The password test restores its original credential in `finally`; workflow cleanup can authenticate either known test credential, and blocks release if the provisioned account cannot be accounted for. Recovery mail is not sent to an invented real inbox.

The previous release is retained. The new application identity remains `app.gocogni.cogni`; Expo project remains `24fc0fea-5e66-4365-a82c-ac668aded7d0`; the signing certificate is checked against the existing one. No live billing activation, store submission or backend migration is performed.
