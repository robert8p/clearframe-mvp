# Nightfall artwork

`approved-dreamscape.png` is a static crop of the Cogni concept supplied and approved in the project conversation. Midnight edge and reading-area fades are composed into the PNG at build preparation time, not rendered as overlapping native gradient views.

The native image-only presentation passed the controlled Android API 36 launch check in run 34155991902 (png-only-wrapper). The complete signed Expo build is tested separately; the diagnostic APK is not a release artifact.

Image: 269 × 235 pixels, 55,764 bytes.
SHA-256: `2ea4004cf994b9f82bba4b5179d71efe020464bb59bf6a2b0e5c47be08386ea9`.

The original WebP source remains solely as provenance. The app references the PNG. Artwork is bundled, decorative, non-interactive and separate from all learning data. Never introduce the concept board's example statistics as real user progress.
